# SugarBloom64
  New unique reverb plugin for Producers, shoegazers, ambience lovers, and sound designers with the goal of full customizable control over your sound.

  VST3 and Standalone for right now.
  Built with JUCE/C++ using limited ai assistance, only using the Claude copilot installed with VSCode to help with some   things I haven't learned how to do yet.
  
  Nine modes: Sugar Convolver, Sugar Reverse, Gated, Hall, Plate, Reverse, Room, Shimmer, and Spring.

  # Sugar Convolver:
  
   Sugar Convolver is a reverb model that turns any sound into a reverb, allowing you to upload your own WAV, MP3, FLAC, AIFF or OGG files. The menu allows you to drag and drop straight from your daw or even from a folder on your computer for easy access This model has tons of features to explore allowing for full creative control over your sound.

  # Sugar Reverse:
  
  Sugar Reverse is a reverse reverb that allows you to modulate random glitch effects on the reverb sound, using a seed that you can randomize from 1-99999. If 0 is set for the seed the modulation will be completely randomized. There is also the option of using a Gate for your modulation that is fully customizable.

Fair warning: Tempo on all features is assumed to be 4/4. I haven't had a change to look into changing that but if people want it I might implement it in a later update.

# For the future of updates:
Im looking into making a native installer that would save you from having to manually change the files with every update, without taking away the option for people who would rather drag the VST into their folder manually.

Im also looking into improving our current reverb models in favor of new features, as most of the development on the plugin thus far has been focused on providing users with tons of customization so it would make sense that the core of the plugin would receive and update next. The models are by no means in a poor state, but along with the features and look feeling top of the line I would like the reverb to sound as high quality as possible as well.
