# SugarBloom64
New unique reverb plugin for Shoegazers and Smartfellas :P
- VST3 for now
Built with JUCE/C++ using as little ai assistance as possible, only using the copilot installed with VSCode.
Eight modes: Gated, Hall, Plate, Reverse, Room, Shimmer, Spring, and Sugar Reverse.

  ## Sugar Reverse
  The reverse engine followed by Grossbeat style glitching effects.
  In version 1.0 the Sugar effect is random but in later versions the
  glitching will be more custom allowing for more modulation and
  allow the user more options to create freely. The glitches are
  essentially sidechain chops like a trance gate that stutters
  inside of a reverse reverb.

For now reverse settings and tempo assume 4/4 for convenience and also idk how to code that shit.
